# 🐍 Python AI & ML MasterClass

This repository contains Python scripts, Jupyter notebooks, and practice implementations from my **AI & Machine Learning MasterClass**. It covers core Python foundations, data handling, visualization, machine learning workflows, and introductory AI concepts.

---

## 🎯 What’s Covered in Python

- **Python Fundamentals for AI/ML:** Data structures, functions, list comprehensions, and clean scripting
- **Numerical & Tabular Data:** Array operations and DataFrame manipulation using **NumPy** and **Pandas**
- **Data Visualization:** Plotting trends, distributions, and relationships using **Matplotlib** and **Seaborn**
- **Machine Learning Workflows:** Data preprocessing, train/test splitting, model training, and evaluation using **scikit-learn**
- **Applied AI & Mini-Projects:** Hands-on Python exercises and problem-solving scripts
